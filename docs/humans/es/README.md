# OpenTokenMini

[English](../../../README.md) · [中文](../zh/README.md) · [Español](README.md)

Sabé cuánto te cuestan tus agentes de código antes de cambiar de modelo.

Tu equipo usa Claude Code, Codex, Gemini CLI o una mezcla. OpenTokenMini registra cuánto cuesta cada llamada, cuánto tarda y dónde falla, lo vincula con los commits y pull requests que produjo, y muestra en qué se va el gasto y qué cambiar. Funciona igual con cualquier agente y cualquier modelo, y es open source: podés leer todo lo que recolecta.

## Instalación

Pedíselo a tu propio agente de código:

- quien es dueño de los datos: "seguí `components/install-owner/AGENTS.md`". Levanta el servicio y te da una dirección y una clave.
- cada máquina de desarrollo: "seguí `components/install-workstation/AGENTS.md`" con esa dirección y esa clave.

No se recolectan prompts ni código. No se recolecta nada antes de activarlo.
