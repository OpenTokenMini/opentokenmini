# Documentation

Placeholder. What agents and non-technical users change in documentation, and what agents can read.

- Reads: page id, space, author, timestamps, edit size. Content only if the owner enables it.

## Coverage (tentative priority)

- First: Confluence, Notion, Google Docs, markdown in repos.
- Next: SharePoint/OneDrive.
- Long tail: GitBook, Slab, Coda.

## Pitfalls

- Content is often the most sensitive data in the org; metadata only unless enabled.
- API permissions are per space: report which spaces were readable, so gaps are visible.
- Telling agent-written from human-written edits is unreliable without harness telemetry from the same user and time.
