# Use case reports

Measured results from teams running OpenTokenMini. Each file is one deployment: what was measured before, what changed, what was measured after. These are the only source for any savings figure in this repo.

## Add yours

Copy `TEMPLATE.md` to `YYYY-MM-<short-name>.md`, fill it in and open a pull request, or send it through the [contact form](https://forms.gle/cqjyqVN9qky4gQ5U6). Any language is fine. You can leave out your company name; the numbers and how they were measured are what matter.

Partial results and cases where nothing improved are welcome too.
