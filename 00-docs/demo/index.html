From clone to dashboard

What happens when you paste the one-line prompt into your coding agent. Numbers are real: one developer's Claude Code logs, last days. Costs are list-price estimates.

1

Your agent reads the repo

Your agent saysThis measures what your AI agents spend, on which work, and what came out of it. I'll go one step at a time and ask before each one. Nothing is collected until you turn it on, and prompts and code are never collected unless you ask for it. Is this for you alone, a team, or a whole company?
2

What you already spent optional, read-only

Your agent saysClaude Code keeps session logs on this machine. I can read the token counts, models, tool names, project folders and timestamps from them to show your last 30 days. I won't read your prompts or code, and nothing leaves this machine.
3

Where the data goes

Your agent saysFrom here on, your agents can report each call as it happens. That data needs a place to go, and you choose it. Pick one:
This machineFor you alone. A small service on localhost; nothing leaves your computer.
A team serverOne service your team sends to, on a VM or container you own. Each developer gets an address and a key.
Your existing backendDatadog, Grafana or any OpenTelemetry collector you already run.
4

Turn on telemetry in your agents

Your agent saysI'm about to turn on telemetry in Claude Code. From now on it will send metadata for every session and turn (tokens, cost estimate, model, latency, errors, which tools ran) to the place you chose. It doesn't send prompts or code. This is the change to ~/.claude/settings.json; to undo it, delete these lines. OK?
  "env": {
+   "CLAUDE_CODE_ENABLE_TELEMETRY": "1",
+   "OTEL_LOGS_EXPORTER": "otlp",
+   "OTEL_METRICS_EXPORTER": "otlp",
+   "OTEL_EXPORTER_OTLP_PROTOCOL": "http/json",
+   "OTEL_EXPORTER_OTLP_ENDPOINT": "http://127.0.0.1:7811"
  }

Same idea for Codex and Gemini CLI, each in its own settings file. The agent sends one short prompt per harness to check that records arrive.
