# OpenTokenMini

[English](../../../README.md) · [中文](README.md) · [Español](../es/README.md)

在更换模型之前，先弄清楚你的编程智能体花了多少钱。

你的团队在用 Claude Code、Codex、Gemini CLI，或者混着用。OpenTokenMini 记录每次调用的费用、耗时和失败位置，把这些数据关联到它产生的提交和拉取请求，并告诉你钱花在了哪里、应该改什么。它对任何智能体和模型都一样适用，而且是开源的：它收集的每一项数据你都能看到。

## 试用

把这句话粘贴给你的编程智能体：

```
Clone https://github.com/OpenTokenMini/opentokenmini and follow its AGENTS.md
```

它会逐步说明，每一步开启前都会先问你。基础安装之后的步骤都是可选的。你可以在提示里加上自己的要求，比如“只用 Claude Code”、“发到我们的 Grafana”或“只看上个月”。

不收集提示词和代码。开启之前不收集任何数据。
